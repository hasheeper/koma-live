**工作区、层级树、画布建骨参考 Spine；自动描绘与精简轮廓参考 Spine Meshes，指针跟随与起点闭合取自 Koma Edit 多边形批注；悬浮面板材质参考 Figma UI3 与 Koma Image。** [Spine Meshes](https://esotericsoftware.com/spine-meshes) · [Koma Edit 实现](../../koma-image/src/native/region-annotator.ts)

## 1. 借鉴 Spine 的核心语法

- **连续画布与就近工具**：画布铺满窗口，顶部居中切换「搭建 / 试动」，下沿悬浮紧凑工具条（选择、建骨、编辑网格、平移、骨骼叠加、缩放与适屏），避免多层嵌套工具栏遮挡角色。[视口](https://esotericsoftware.com/spine-ui#Viewport) · [变换工具](https://esotericsoftware.com/spine-tools#Transform-tools)
- **语义化 DCC 层级树**：左侧双列极简状态槽（显隐圆点 + 锁定），按对象类型区分着色微图标（插槽环、图像、双色网格、实心骨骼锥、零长度点关节十字），展开箭头折叠分支，点击与悬停在画布与树之间双向同步。[树节点](https://esotericsoftware.com/spine-tree#Tree-nodes) · [选区](https://esotericsoftware.com/spine-tree#Selection)
- **清晰的建骨手势**：搭建模式下选中父骨，拖拽默认吸附父骨尖端建子骨；按住 `Alt` 拖拽可从任意落点建立偏移子骨（用于肩部、四肢等）；单击可建立零长度点关节。[建骨工具](https://esotericsoftware.com/spine-tools#Create-tool) · [骨骼](https://esotericsoftware.com/spine-bones)
- **简化的蒙皮认知**：参考 Spine 权重列表的「核对驱动骨」思路，但不引入逐顶点权重笔刷；单张跨关节切片只需拾取起骨与末骨形成连续骨链，并调节单一的「关节柔化」像素宽度。[骨骼列表](https://esotericsoftware.com/spine-weights#Bones-list)

## 2. 工作台上的对应操作

| 作者要做什么 | 去哪里 | 可见结果 |
|---|---|---|
| 找到或排序图层 | 左侧「层级树」查图层与附件；切到「绘制顺序」拖拽或点行尾微调箭头重排遮挡。 | 选中行与画布部件同步高亮；调整层序实时更新 WebGL 遮挡且可撤销。 |
| 搭建与整理骨架 | 底部工具条选「建骨 (`B`)」（按住 `Alt` 建偏移子骨）；在右侧检查器点击骨名（或双击树节点 / `F2`）改名、拾取改父骨、设为根骨或删骨。 | 树中按 `parentBoneId` 清晰缩进；改父级不移动原画静止像素；删骨前自动校验引用。 |
| 绑定单骨或骨链 | 选中图层，在右侧检查器起骨/末骨槽点拾取器，从画布或树点选骨骼；骨链可拖调「关节柔化」。 | 画布实时预览候选骨链与柔化过渡带，静止像素保持原位对齐。 |
| 编辑或清除轮廓网格 | 搭建模式下点底部网格图标或双击层级树中的附件行进入；支持手绘、自动描绘（Trace）、加点/删点/吸附，及标题栏垃圾桶图标一键清除。 | 顶点吸附显示对齐导线，取消/应用完整接入撤销栈。 |
| 验收骨骼完整 TRS | 切到顶部「试动」，画布直接拖转骨身，或在右侧检查器拖调 **旋转 / 平移 X·Y / 缩放 X·Y** 并一键复位。 | 父骨 TRS 自然传导到子骨与骨链；翻面或自交三角形在画布上标红高亮。 |

## 3. 克制取舍：做什么，不做什么

- **聚焦做透**：精绘切片的像素级原稿复原、直观的 2D 骨架与连续骨链自动蒙皮、快速轮廓网格、完整骨骼 TRS 试动验证，以及面向前端代码美术的 `rig-spec.json` 与 `mountLiveRig`。
- **刻意不做**：不在工作台引入繁琐的全局参数键形表单（避免像传统参数面板那样切碎整体表演、束缚 AI 代码美术的自由度），也不做手工逐顶点刷权重、重型时间轴/曲线编辑器或通用 IK。Rive 的 Design/Animate 分界用于维持搭建（Rest Pose）与试动预览的数据隔离；若未来对特定部位（如水母伞帽）需要骨骼缩放之外的局部形变，再按需评估轻量图层局部形态，而不回退到全局参数系统。
