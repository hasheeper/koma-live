# Koma 系动画设计哲学与演进路线

> **定位**：本文沉淀 **Koma Image（拆层补画）→ Koma Rig（骨架与安全网格）→ Koma Live（代码连续物理与审片闭环）** 整套管线的创作总纲、工艺红线与下一阶段引擎演进清单。[核心规格](rig-spec.md) · [演出契约](performance-contract.md) · [动帧视觉验收](live-inspection.md)

## 一、核心理念：新时代的「赛博皮影戏」

**Koma（コマ，漫画的一格）** 的本义，是让一格高颜值的静态精绘立绘自己长出呼吸与体温，而不是把它强行改造成 3D 播片。

本质上，这套范式通过 **「图像 AI 自动化拆层补画 + 代码实时驱动连续物理」**，将 2D 骨骼动画从昂贵的商业手工业降维成边际成本趋近于零的表达媒介，让动态彻底退居幕后，重新服务于角色灵魂与叙事。

### 四句创作总纲

> 1. **像素只管美，代码只管真**：画师/AI 精绘定稿与高定手绘差分零妥协，运动与物理交给确定性代码演算。
> 2. **八分画格定力，二分末梢呼吸**：锁死核心构图与重心，用克制微视差与分材质重量梯度营造在场感。
> 3. **拒绝模板与炫技，按物种写物理**：不同材质各自服从真实力学（刚体、重力铅垂、折纸折痕、薄纱空气、粘滞流体），动画隐身于角色性格之后。
> 4. **零成本重来，把裁决权还给导演**：实时热重载与无头确定性审片闭环让试错成本趋近于零，对一切违和动态零容忍。

### 五大支柱

1. **像素与运动的彻底解耦（图像域锁死颜值 + 数学域驱动物理）**
   不强迫生成式视频在像素空间赌运动恒常性，而是划清像素域与骨骼域边界：上游在 [Koma Image · Koma Layer](https://github.com/hasheeper/koma-image/blob/main/docs/workspaces/layer.md) 完成高质量定稿、40+ 图层细拆与局部补画，锁死画风与线条；下游用 WebGL 骨骼 TRS、代码原生网格变形场（`deform`）与单文件 JS 实时演算，由 Agent 配合 `inspect:live` 完成物理编写与轨迹验收。
2. **反「炫技综合征」，追求「在场感」而非「表演感」**
   抛弃为证明经费充足而拉满的全屏果冻弹簧晃动与舞台剧式大动作。动画不是“演给玩家看”，而是让角色在画格里拥有体温、非对称呼吸、微眼神与情绪耦合——**像呼吸一样隐形，却让人心动**。
3. **消除沉没成本，夺回「导演选择权」**
   传统手 K 关键帧把修改变成昂贵的沉没成本，迫使创作者向半成品妥协。单文件 JS 热重载把“推倒重来”的代价压到几分钟，创作者从体力劳动回归片场导演，门槛也从“拼工时”纯化为**拼审美直觉、材质理解与角色灵魂**。
4. **反暴力伪 3D，拥抱 `±X°` 克制微视差**
   放弃传统 Live2D 试图用九宫格变形器硬捏 30°~45° 大转头的执念（极易扯烂原画五官比例）；改采 **「80% 构图稳如画格 + 5~6 层深度微视差 + 20% 末梢物理延迟」**，在极克制角度内拉开雕塑般的纵深空气感，同时保证正面原画颜值零破坏。
5. **无时间轴的连续状态场（代码美学驱动生命感）**
   告别时间轴播片切换时“吸半口气突然重置 / 惯性归零 / 等归位再播”的顿挫感。用实时动力学状态机驱动一切，通过多频错相、非对称呼吸、弹簧动量延续与实时光影联动，让角色成为随时响应意图与环境的微型生命体。

## 二、与 Spine / Live2D 及生成式视频的范式边界

| 对比维度 | 生成式视频 | 传统 Spine / Live2D（时间轴 Clip + Mix） | Koma 代码演算（连续状态场） |
| :--- | :--- | :--- | :--- |
| **画质与风格恒常性** | 概率插值，线条与画风必然漂移 | 100% 锁死原画 | **100% 锁死原画** |
| **动作切换底层机制** | 不可实时交互的死视频 | 预烘焙剪辑插值混合（只插值位置，易断呼吸与速度惯性） | **连续力场 + 弹簧动量延续**（呼吸、微风、速度永不重置，任意时刻无损打断） |
| **因果联动方式** | 黑盒不可精调 | 需动画师把主副运动全手工烤死在同一个 Clip | **改意图权重，次级运动自动因果推演**（抬手→衣摆张力→配饰惯性→光影联动） |
| **最擅长的业务场景** | 一次性非交互影视镜头 | 强编排、踩音乐节拍的固定表演大招 / 复杂多段格斗过场 | **强陪伴、强交互、随时响应对话/鼠标/环境信号的活立绘与生态箱角色** |

> **如何优雅处理离散贴图切换（表情差分 / 漫符 / 姿态换件）**：连续物理无法把两张不同 PNG 直接平滑变形，Koma 的标准范式是**「用连续动力学包裹并藏住离散瞬间」**——例如切换眼部差分时，通过分段单调网格形变将上眼睑完整压合至 `~3 px` 闭缝、落入闭眼差分谷底再缓睁（眨眼桥接）；未来做肢体换件时，则在摆臂速度峰值或衣袖遮挡帧瞬切 `slot` 并用二阶弹簧接住余韵。

## 三、四大创作与工艺红线

### 1. 三轴微视差安全区间（不崩脸的 `±X°` 边界）

人脑感知立体感主要靠 **5~6 个深度层的相对位移速度差**（前发/角尖 → 五官 → 脸颊/发冠 → 鬓发 → 耳饰/蝴蝶结 → 后发），而不是把脸硬转到侧面：

| 旋转轴 | 黄金无损区（0 崩脸） | 极限可用区（简鼻二次元 + 微形变） | 崩脸红线 | 核心原因 |
| :--- | :--- | :--- | :--- | :--- |
| **Yaw 左右转头** | **±8° ~ ±12°** | ±15° | > ±18° | `±10°` 透视缩短仅 `1.5%`；超过 `15°~18°` 鼻梁与远眼必须发生三维自遮挡，平面图必滑脸 |
| **Pitch 抬头/低头** | **仰 +6° ~ 俯 -10°** | 仰 +9° ~ 俯 -14° | 仰 > +12° / 俯 > -16° | **俯视远比仰视安全**；原画通常未画下巴底面、鼻底与仰视颈喉 |
| **Roll 左右歪头** | **±8° ~ ±15°** | ±20° | 仅受颈肩连接限制 | 纯平面旋转无透视畸变，配合**重力铅垂回落长发**最出情绪 |
| **Body Yaw 躯干微转** | **±5° ~ ±8°** | ±10° | > ±12° | 肩锁骨与衣领起伏大，超限易产生“肩膀拉面条” |

### 2. 物种与材质物理分级（拒绝千人一面弹簧模板）

演出脚本必须按角色实际材质建立阻尼与重量梯度，而不是给所有部位套同一组正弦波：
- **刚体与金属（石角、铁铐、铁链、机械肢）**：严禁缩放拉伸（`scale === [1, 1]`），铁链仅吃**纯重力与惯性（零风力）**，正面直立腿严禁用 2-Bone IK 垂直压低造成“香蕉膝盖”。
- **厚重长发**：高阻尼（`ζ ≈ 0.72~0.85`）、零均值间歇轻风、`s³` 单曲率 C 弧、**严格弧长守恒**（`dy = -dx² / 2L`，绝不做上下拉伸“水草波”），头歪时对刘海与鬓发做强重力铅垂反补偿，外侧附生细发丝必须挂在对应主发束父骨下共享根部变形。
- **丝带与薄纱裙摆**：折纸丝带用 2~3 节短骨链沿原画折痕弯折；多层半透明衣物按前后层差做相位滞后、手提悬链线张力与边缘涟漪。
- **异质流体与生态体（深海凝胶伞帽、触手、原质黑泥）**：高粘滞缓慢蠕动、地面锚定与同轴叠亮辉光。

### 3. 较大肢体动作的四级补件策略

| 动作层级 | 典型动作 | 正确落地方式 | 成本与一致性风险 |
| :--- | :--- | :--- | :--- |
| **一级：微动与微视差** | 呼吸、±10° 转头、歪头、眼神漫符、发裙垂坠 | 纯骨骼 TRS + `deform` + 表情 `slots` | 极低，100% 锁死原画 |
| **二级：中幅肢体动作（±30°~45°）** | 轻抬手、提裙、招手、耸肩、微前倾 | 上游 **A 类遮挡补全**（补腋下/侧腰底洞）+ 肘肩**圆包边重叠关节** + 衣袖跟随网格 | 极低，无需画新透视件 |
| **三级：标志性手势 / 局部换件** | 伸手、捂嘴、托腮、拿道具、翻掌手势 | **同画布局部重绘（Inpaint）→ 像素差分抠件** + `slots` 换件（严禁白底单画孤立零件） | 可控，每角色精选 1~3 个高辨识手势 |
| **四级：彻底改变体态与构图** | 坐下、蹲抱、大转身、跨视角动作 | **不在单张皮影里堆几十套换件，直接 AI 生成下一张新构图活画格** | 最契合低成本理念，零画风撕裂 |

### 4. 面向 AI 生成图的阴影「三区动态脱影」原则

AI 生成图在定稿时已顺手绘制了极高质量的插画光影，**全图算法投影反而会产生廉价“剪纸打硬灯”的 3D 伪人感**。阴影遵循三区取舍：
1. **原生锁定区（~75%）**：脸颊明暗、鼻影、裙褶与发束固有影——**0 算法阴影，100% 吃满 AI 原画**；
2. **克制微动区（~15%）**：微风刘海下额头、鬓发侧脸——在 `±8°~12°` 小位移下保留 AI 柔和底影，不开硬投影；
3. **按需手术区（~10%）**：仅针对**大位移贴身悬空物**（大幅扫裙铁链、大抬臂）与 **B 类新增换件**（底图原本无影的新手势/道具），作为**默认关闭、按需点选**的极克制柔乘算投影工具使用；上游拆层时也仅擦净这些大位移遮挡物的硬旧影，绝不教条式全图去影。

## 四、Koma Live 基础设施边界与极简克制原则

### 1. 性能实测基线

在重度角色样板（105 图层、72 骨骼、28 个实时网格变形场、6,183 活跃三角形、`1408×2944` 画布）上的 400 帧空载实测表明：
- 开启开发期全量几何自检 `checkGeometry()`（`validateGeometry: true`）时，单帧 CPU 约 **`16.50 ms`**（顶到 60fps 预算红线）；
- 播放态关闭自检（`validateGeometry: false`）后，全套 JS 演出物理（`0.038 ms`）+ 骨骼解算、蒙皮与 28 个网格变形场（`0.766 ms`）合计仅 **`0.804 ms/帧`**（仅占 60fps 预算 **4.8%**，**实测提速 20.5×**）；
- 同时将非 `gelGroups` 常规纹理改回 `rgba8unorm` 后，单角色显存占用直降约 **50%**（`~135 MB → ~67 MB`）。

### 2. 已收口落地的基础设施（引擎底盘稳定封板）

纯 JS 路径本身已足够强大，引擎层只收口了以下 **4 项实测刚需的轻量基础设施**，绝不盲目堆砌复杂特性：

1. **运行期 `validateGeometry` 开关 + 按需纹理精度（已落地）**
   - `rig.pose()` 底层保持默认 `true`（Studio 搭建/试动、离线 CLI、`inspect:live` 审片全程全检）；`mountPerformance` / `mountLiveRig` 播放态默认 `false`（单帧 CPU 实测提速 **20.5×**，Koma Live 页面开启「审查」叠层时动态切为 `true` 实时标红）。
   - 仅 `gelGroups` 半透明合成组保留 `rgba16float`，其余常规切片默认 `rgba8unorm`，显存立省约 **50%**。
2. **`setPose` 透传逐层 `opacity` 与 `tint`（已落地）**
   - 演出脚本可直接通过 `puppet.setPose({ ..., opacity: { layerId: 0..1 }, tint: { layerId: 0xRRGGBB } })` 控制单层透明度与受光染色（`peekOpacity` 透发层同步继承）；无需再回 `rig.json` 写死占位 `parameters + drives`。
3. **通用图层 Alpha 裁切蒙版 `clipTo`（已落地）**
   - 支持在 `rig.json` 的 `layerSettings` 声明 `clipTo: "<目标图层ID>"`，也支持在 `setPose({ clipTo: { layerId: targetId | null } })` 动态切换或清除；
   - WebGL 层直接复用目标图层本帧实时变形后的 Alpha 轮廓（多图层裁切到同一目标时共享单次离屏通道，未启用时零开销），彻底解决瞳孔裁眼白、脸红与转面微暗裁脸廓的越界隐患。
4. **移动端轻量化双开关：`rig export-work --scale 0.5` 与 `layerResolutionScale`（已落地）**
   - 导出包支持 `npm run rig -- export-work <作品> <输出> --scale 0.5`：对贴图执行预乘 Alpha 防黑边 Lanczos 降采并在导出 `manifest.json` 写入 `textureScale: 0.5`，**`rig.json` 与单文件演出脚本 100% 零改动**（UV 归一化直接映射回 1× 逻辑画布），磁盘体积与 GPU 显存同步降至 **1/4**；
   - `mountPerformance` 支持 `layerResolutionScale`（如 `0.5`），将同轴 `back`/`front` 2D 柔光画布缓冲分辨率减半（填充像素立减 **75%**），逻辑坐标系依然保持 1× 零偏移。

### 3. 明确不做的项（反过度工程化）

- **现阶段明确不做**：声明式层间算法阴影（`castShadows`，AI 原画光影已足够优秀且全算易显 3D 伪人感）、自动打合图（Texture Atlas）、运行期动态 `zOrder` 重排、复杂顶点对象池、网页端洋葱皮 UI。
