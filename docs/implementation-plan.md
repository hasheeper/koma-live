# Koma Rig 功能规格

本文是通用分层 2D 绑骨底盘与求值内核的功能和验收基线。Koma Rig 负责把精绘分层切片变成像素保真、结构清晰、带几何安全护栏的可动 2D 人偶；动画本身作为一个整体，可由前端代码或 AI（如程序化代码美术）通过实时 API 直接驱动整套骨架，也兼容离线静态动作片段。[离线制作与命令](offline-authoring.md) · [工作台说明](studio-layout-plan.md)

## 1. 核心对象与分工

| 对象 | 它负责什么 |
|---|---|
| 图层 | 一块有稳定身份的图像，记录贴图、裁切矩形、原画布偏移和绘制顺序。画面里的像素来自图层。 |
| 骨骼 | 可独立存在的控制对象。静止姿势记录父空间起点、朝向角与长度；运行时支持完整 **TRS（父空间平移 `x/y`、顺时针旋转 `rotation`、正倍率缩放 `scaleX/scaleY`）**，求值给出世界矩阵与实时起终点。 |
| 骨架 | 一组骨骼及其显式 `parentBoneId` 父子关系。父骨的平移、旋转和缩放沿树传导到子骨与附着部件。 |
| 绑定 | 记录图层由哪根单骨（`boneId`）或哪条连续母子骨链（`boneChain`）驱动；单骨与骨链均可驱动多张图层。 |
| 轮廓网格 | 承载一张纹理的顶点、三角形和 UV（`bindings[].mesh`），支持手绘轮廓与 Alpha 自动描绘。 |
| 局部变形器（可选） | 内核可选支持 FFD 晶格（`3×3` / `4×4`）和 Ribbon 条带，在局部空间按标量参数平滑形变；常规摆动与弹性优先由骨链和骨骼 TRS 完成，不强制绑定变形器。 |
| 差分槽（可选） | 用于透视或拓扑变化（如垂手↔抬手、闭眼线）的离散切片切换，每步只显示一种形态。 |
| 驱动清单（`rig-spec.json`） | `exportRigSpec` 导出的轻量结构摘要（`koma-rig.spec.v1`）：声明坐标系、骨骼树、图层归属与差分槽，供前端或 AI 代码美术直接驱动 `mountLiveRig`。 |

**文件关系。** `rig.json` 的 `bones[]` 保存独立骨架，`bindings[]` 记录图层绑定与可选网格/变形器，`drawOrder` 独立保存由后至前的绘制顺序。旧稿的 `bindings[].parentId` 与语义 `parameters` / `motions/*.json` 作为离线兼容能力保留。[骨架求值](../packages/rig-core/src/skeleton.ts) · [图层求值](../packages/rig-core/src/pose.ts) · [AI 驱动清单](../packages/rig-core/src/spec.ts)

## 2. 骨架、绑定与完整 TRS

用两张带刻线的纸条检验刚性绑定，再用一张完整纸带检验跨关节弯折。

| 作者要完成的事 | 可观察的通过条件 |
|---|---|
| 建立父骨、吸附子骨与偏移子骨（`snap: false`） | 骨骼可分别识别；仅建骨时不改变原画静止像素。 |
| 改名、改父骨（`reparent`）、设为根骨、删骨 | 改父级自动重算局部坐标以保持静止世界位置不变；循环父级或删除仍被引用的骨骼时整批操作原子失败并指明原因。 |
| 绑定单骨或连续骨链，调整绘制顺序 | 图层按 `drawOrder` 遮挡，与骨架继承互不干扰；改绑、解绑与撤销均在静止姿势计算，回到静止姿势后像素与参考图对齐。 |
| 试动骨骼完整 **TRS** | 父骨平移、旋转、缩放均自然传导到子骨与骨链；根骨平移直接在画布坐标生效（不受根骨静止朝向角干扰）；非正缩放（`≤ 0`）被拒绝。 |
| 保存重开与冲突保护 | 重开后精确复现骨架、绑定、网格与层序；外部修改磁盘文件时拒绝静默覆盖。 |

坐标统一使用原画布像素：左上为原点，`+X` 向右、`+Y` 向下，画面顺时针为正角。Known reference：绕 `(100, 80)` 顺时针转 `4°`，原位置 `(125, 80)` 落到约 `(124.939, 81.744)`。

**静止与动态骨骼矩阵。** 每根骨骼在静止姿势保存 `boneId`、`name`、可选 `parentBoneId` 与父空间 `x, y, rotation, length`（零长度为点关节）。运行时支持传入 `BoneTransform = { x?, y?, rotation?, scaleX?, scaleY? }`：
- `x / y`（默认 `0`）：在**父空间**（根骨即画布空间）叠加到 `(b.x, b.y)`；
- `rotation`（默认 `0`）：顺时针角度增量；
- `scaleX / scaleY`（默认 `1`，须 `> 0`）：分别沿骨身方向与垂直方向缩放。

骨骼世界矩阵为 `W父 · T(b.x + tx, b.y + ty) · R(b.rotation + Δθ) · S(sx, sy)`，终点为 `W骨 · (length, 0)`。改变静止显示长度不会重新定位已有子骨。

**绑定与改绑。** 全部在 Rest Pose 计算：`L偏移 = inverse(W新骨静止) · W图层静止`（保存为 6 分量 `restOffset` 与裁切原点 `bindOrigin`），以便换图扩边后按原画布坐标准确贴回。临时试动只进入预览，绝不污染静止偏移。[两段纸条操作](../examples/hinge/setup.json) · [矩阵与 TRS 回归](../packages/rig-core/test/authoring.test.ts) · [TRS 与驱动清单测试](../packages/rig-core/test/spec.test.ts)

### 2.1 一张完整切片跨骨链自动蒙皮

同一张切片可绑给一条连续母子骨链 `boneChain: ["base", "tip", …]`（至少两根，逐项校验直接父子关系）。作者只需调节单一参数 `jointSoftnessPx`（关节两侧过渡半宽，默认最短投影段的四分之一，上限为相邻短段的一半）。

内核在静止链上按弧长投影求权重，在关节带用 smoothstep 混合相邻骨骼的完整仿射变换并在关节附近自动细分三角形，保留原轮廓网格与纹理。无论是旋转、平移还是挤压拉伸，骨链都能平滑跟随，无需手工逐顶点刷权重。[单层纸带示例](../examples/chain-strip/setup.json) · [骨链回归](../packages/rig-core/test/chain.test.ts)

## 3. 轮廓网格、几何体检与可选局部变形

| 能力 | 机制与通过条件 |
|---|---|
| **轮廓网格（`bindings[].mesh`）** | 支持手绘多边形轮廓或按切片 Alpha 自动描绘（Trace），并可加点、删点、吸附微调与一键清除（`mesh: null`）。接受后的拓扑在导出重开后完全复现。 |
| **实时几何体检（核心安全网）** | 对最终世界顶点检查静止有向面积 `A₀` 与当前面积 `Aₜ`（要求 `|A₀| > εA`、`sign(A₀)·Aₜ > εA`、`Aₜ/A₀ > εJ`），并另查同一变形面内非相邻三角形的边交叉、共线重叠与包含。失败时抛出带出错三角形坐标 `polygons` 的 `GeometryError`，工作台直接在画布标红定位。 |
| **可选变形器（FFD / Ribbon）** | 内核支持 `3×3` / `4×4` 贝塞尔晶格（可锁边）与 Catmull-Rom 条带，并支持与轮廓网格、骨链叠加求值。定位为**按需局部软体补充**（如纯缩放难以模拟的非均匀膨胀），不作为强绑全局参数的前置门槛。 |

## 4. 素材、图层身份与像素复原

- **导入。** 美术在绘图软件拆层、补画与烘焙复杂效果。离线 PSD 导出器生成 `manifest.json`、`textures/*.png` 与独立导出的 `reference.png`，保留原画布尺寸、精确像素偏移、组树、可见性、不透明度、层序与稳定 `layerId`。
- **重导。** 同一 `sourceId` 内优先沿用 PSD 原生图层 ID（`lyid`），改名后自动认回；删层重建、重复 ID 或拆并由作者用 `--map` 显式映射。
- **像素复原与 PMA。** v2 在 sRGB 空间按原纹素预乘一次，过滤、遮罩与离屏合成全程保持 PMA；逐像素对照独立 `reference.png` 检查超差像素与差异热图，确保换图和导出不失真。
- **同深度合成组（`gelGroups`）。** 共享同一半透明表面的相邻图层按覆盖率轮廓抠除（`U + (1 - k)G`）后统一施加一次组不透明度，消除半透明接缝重影；调整绘制顺序时整组保持连续不拆散。

## 5. 驱动方式：实时代码美术为主，静态动作兼容

Koma Rig 不再用死板的预设参数表去切碎动画或限制 AI 的表达，而是提供**两条定位清晰、共享同一套安全底线的驱动通道**：

### 5.1 主通道：前端程序化代码美术直驱（`mountLiveRig` + `rig-spec.json`）

- **人负责底盘**：在工作台或 CLI 完成切片复原、骨架命名、父子层级、单骨/骨链绑定、轮廓网格与绘制顺序，导出 `rig.json` 与 `rig-spec.json`（`exportRigSpec`）。
- **AI / 前端代码负责整体表演**：读取 `rig-spec.json` 后，直接编写 `requestAnimationFrame` 程序化动画控制器，调用 `mountLiveRig` 的 `setPose({ bones, slots, parameters, timeMs })`：
  - 将整套骨架的平移、旋转、缩放作为一个有机整体编排（多频呼吸、骨链相位错落波浪、鼠标视线追踪、游戏生态状态联动）；
  - 利用 `setPose` 返回的实时骨骼起终点与部件中心点，在 WebGL/Canvas 层自由叠加粒子、焦散、呼吸光环等前端代码美术特效；
  - 无需经过静态关键帧表，也不要求提前给每根骨骼手建语义参数。
- **安全护栏由内核实时兜底**：所有实时姿势都经过同一 `rig-core` 求值（非有限值拦截、非正缩放拦截、骨链自动蒙皮、`GeometryError` 翻面/自交检测）；若单帧越界，调用方可捕获错误并保持上一有效帧不崩溃。

### 5.2 兼容通道：离线静态动作与审计归档（`motions/*.json` + `mountPublished`）

对于需要离线批量出片、无代码静态播放或发布包哈希归档的场景，内核与 CLI 完整保留既有静态管线：
- `exportCapabilities`（v3，输出参考区间 `referenceRange` 与差分槽）与 `validateMotion`；
- PCHIP 单调三次插值（`--loop`）、10 ms 固定步次级弹簧与打断平滑退场（`createInteractionPlayer`）；
- `rig audit` / `rig review` / `rig publish` 生成带逐文件 SHA-256 的静态发布包，由 `mountPublished` 挂载。

## 6. 当前能力核对

| 模块 | 当前已验证能力 |
|---|---|
| **PSD 与像素复原** | 离线导出 v2 切片、原生 `lyid` 与 `groupTree`、同深度 `gelGroups`、`verify-slices` 逐像素预乘比对与差异热图、`reimport --map` 换图迁移。 |
| **骨架与 TRS** | 建骨、吸附/`Alt` 偏移子骨、改名、改父级、设为根骨、删骨（引用拦截）、单骨/连续骨链自动蒙皮与柔化、完整骨骼 **TRS（平移·旋转·缩放）** 求值与继承。 |
| **图层与轮廓网格** | 显隐、锁定、绘制顺序拖拽/微调（含 `gelGroups` 整组保护）、手绘轮廓、Alpha 自动描绘、顶点编辑/吸附、清除网格、`GeometryError` 画布标红高亮。 |
| **实时运行时与 AI 清单** | `exportRigSpec`（`koma-rig.spec.v1`）与 `mountLiveRig`（独立构建入 `packages/rig-renderer/dist/runtime/player.js`，零编辑器依赖），支持静态目录 URL 或内存资产实时 TRS 驱动。 |
| **离线 CLI 与归档** | `import / edit / undo / redo / save / preview / render / sample / audit / review / publish` 全链路可用；可选变形器（FFD / Ribbon）与静态动作兼容保留。 |
