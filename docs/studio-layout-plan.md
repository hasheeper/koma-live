# Koma Rig 工作台说明与布局规范

从仓库根目录运行 `npm run dev -- --host 127.0.0.1 --port 5186` 打开工作台。桌面画布铺满窗口；**244 px** 左侧层级树和 **240 px** 右侧属性检查器悬浮于两侧。搭建、试动、网格编辑与选区拾取共用这套紧凑结构，定位为纯粹的 **2D 精绘立绘绑骨校准台**。[本地开发地址](http://127.0.0.1:5186/) · [功能规格](implementation-plan.md) · [编辑器参考](editor-references.md)

## 1. 设计准则：对象、属性与画布

大纲树回答「选中了谁与前后遮挡」，检查器给出所选对象的属性和操作入口，中央画布提供直观的空间编辑。三处共享选区与悬停反馈。

- **尺度与呼吸感**：面板正文 `12 px`，ID、单位与数值 `11 px`。面板圆角 `12 px`，距窗口边缘及工具岛 `10 px`。树行高 `24 px`，保留 `8 px` 左右内边距与 `6 px` 行圆角，避免生硬贴边表格感；选中行使用主题青色微光底（`--row-selected`），悬停与选中状态分离。
- **Spine 风格左树状态槽与语义图标**：显隐圆点与锁定图标收拢在左树最左侧两列窄槽，用一条极淡竖线与内容区分隔；对象图标采用高辨识度 DCC 语义着色（图层插槽环、图像、青橙双色网格、实心窄锥骨骼、点关节十字）。
- **检查器栅格与图标化操作**：检查器抬头单行显示语义图标、对象名称（骨骼搭建态支持点击原地改名）与右对齐 ID 徽章；属性标签固定 `72 px`，骨槽、数值凹槽与开关凹槽统一高 `25 px`、圆角 `6 px`、间距 `6 px`；分组标题栏右侧操作统一采用 `22 × 22 px` 图标按钮（垃圾桶删除/清除、逆时针复位、骨链分支重选、自动阈值、收起），避免冗长文字堆叠。
- **布局回归护栏**：运行 `npm run test:studio-layout` 在 Chromium 中打开生产构建，自动校验深浅两套主题下的画布适屏、连续缩放网格、标签对齐、凹槽尺寸、选中背景色与窄屏响应式布局。首次运行前可用 `npx playwright-core install --only-shell chromium` 安装测试浏览器。

## 2. 固定工作区与核心交互

| 位置 | 当前能力与交互 |
|---|---|
| **顶部工具岛** | 左上为品牌标识、企划菜单与撤销／重做（`⌘/Ctrl Z`、`⌘/Ctrl Shift Z`），正中为「搭建 / 试动」等宽切换，右上为「动帧 Live」一键切换、深浅主题与层级树开关。企划菜单统一兼容打开 `koma-work.json` 作品根目录与 v2 切片目录（Worker 自动复验像素与参考图，缺失 `rig.json` 时内存合成 `setup.json`）、支持 IndexedDB 最近目录一键恢复与开发态 `?work=` / 本地工作区快捷切换、画布拖放目录或 `rig.json`、原位保存或从目录重新载入 `rig.json`（外部改动自动同步或轻提示）、**导出 AI 驱动清单 `rig-spec.json`**，以及切换内置练习示例。 |
| **主画布与工具条** | 贯穿原稿内外的连续像素网格（暗 `#17181B` / 浅 `#E2E4E8`），随缩放连续显隐细刻度。下沿居中悬浮工具条，按钮统一等宽方格与视觉居中图标，集中选择（`V`）、建骨（`B`）、编辑网格、平移（`H` / 空格）、骨骼叠加、缩放与适屏（`F`）。试动时遇到三角形翻面或自交，画布直接用警示红填充与描边高亮出错三角形。 |
| **左侧层级树** | 仅保留纯粹的 **`图层` + `骨骼`** 两支（不引入繁琐全局参数表），与「**绘制顺序**」页签切换，支持搜索定位。图层行可切显隐与锁定；双击骨骼原地改名，双击附件行直接进入网格编辑。在「绘制顺序」页签（搭建态）支持**行拖拽重排（带 2px 青色落点线）**与悬停上/下微调，自动保护 `gelGroups` 同深度合成组连续性。 |
| **右侧检查器** | 随选区自动切换三套对称检查器：<br>• **图层 / 绑定（`BoneBinding`）**：起骨/末骨槽点拾取器从画布或树点选单骨/骨链，支持整链重选、解绑、「关节柔化」拖调，以及骨链尚无轮廓网格时的一键「生成骨链轮廓网格」（低凹度防翻面预设，可撤销）。<br>• **骨骼（`BoneInspector`）**：搭建态支持点击/`F2` 原地改名、拾取改父骨（自动屏蔽自身与后代防循环）、一键设为根骨、直接拖调静止 `局部 X/Y/角度/长度`、垃圾桶/`Delete` 删骨（带引用数量拦截提示）；试动态提供完整 **TRS（旋转 / 平移 X·Y / 缩放 X·Y）** 5 凹槽与一键复位。<br>• **轮廓网格（`MeshInspector` + `TracePanel`）**：分三段式布局（网格信息 + 自动描绘独立分组 + 底部固定「取消/应用」栏），支持手绘轮廓、Alpha 自动描绘与自动阈值估算、加点（`A`）/删点（`D`）/移动（`V`）/吸附（`Alt` 临时关闭）/方向键微调，以及垃圾桶一键清除自定义网格还原为图像。 |

**画布骨骼绘制与手势。** 骨骼采用带阻尼缩放因子的细长实心锥（缩小时不过粗、放大时不过细），常规状态只绘根关节小圆，仅在搭建态选中或悬停时显示尖端拖拽圆环；悬停与选中状态独立渲染，支持画布与层级树双向悬停高亮。建骨工具（`B`）在选中父骨时默认吸附父骨尖端，**按住 `Alt` 拖拽**可从任意画布落点创建偏移子骨（并绘制父子淡虚线预览）。

## 3. 已交付范围与后续按需演进

当前工作台已完整打通 **「切片复验 → 骨架搭建（含改名/改父骨/删骨/`Alt` 偏移子骨）→ 单骨与骨链绑定 → 绘制顺序重排 → 轮廓网格编辑/清除 → 骨骼完整 TRS 试动与翻面标红 → 导出 `rig.json` 与 `rig-spec.json`」** 闭环，并可直接配合独立构建的 `mountLiveRig`（`packages/rig-renderer/dist/runtime/player.js`）由前端代码美术实时驱动。

**架构边界**：`rig-studio` 只管选区、工具、撤销历史与本地文件读写；`rig-core` 管骨架、绑定、TRS 求值与几何体检；`rig-renderer` 管 WebGL 纹理与合成。高频顶点与 Pixi 实例留在 Vue 深层响应式之外，网页可直接静态部署。

**后续按需评估（不预设硬排期）**：
- Koma Live 网页端暂停态轻量洋葱皮开关（见 [动帧视觉验收](live-inspection-plan.md) 第三步）；
- 浏览器端未保存草稿自动恢复与 ZIP 企划包导出。
- *(已落地：IndexedDB 最近目录句柄恢复、Studio ↔ Live 会话保活与全量自动热重载、以及运行时零 UI 负担的 M4 代码原生顶点变形口 `deform` Mesh Field。)*
